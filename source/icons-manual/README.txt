Hand-picked app icons go in this folder.

  File name:  <app id>.png      for example  google-chrome.png   (same id as in source/apps.json, all lowercase)
  Format:     PNG only, 128x128 or 256x256 pixels, roughly square, under 200 KB
  Free apps:  only free apps get icons

A file here always wins over the automatic icon. Delete the file to go back to the automatic icon.
See README.md, section "Icons".
